End Device Finder

Trace a device from IP address to MAC address and then to the physical switch port.

What information do you have?

{% if ip %}

Step 1: Find the MAC address

You know the endpoint IP: 

{{ip}}

Cisco command 

show ip arp {{ip}}

This searches the ARP table for the IP address.

Look for

Find the MAC address associated with the IP address.

Example: 

Internet  {{ip}}  3  0050.56aa.bbcc  ARPA  Vlan20

From this output:

  • IP = {{ip}}
  • MAC = 0050.56aa.bbcc
  • Layer 3 interface = Vlan20

Next step

Copy the MAC address from the ARP output and enter it in the MAC field above.

{% endif %} {% if mac %}

Step 2: Find the switch port

MAC address: 

{{mac}}

Cisco command 

show mac address-table address {{mac}}

This searches the switch MAC address table.

Example result 

Vlan    Mac Address       Type        Ports
20      {{mac}}           DYNAMIC     Gi1/0/24

In this example the device is learned from: 

Gi1/0/24

Step 3: Check the interface

Once you identify the port, verify its status. 

show interfaces status

For more detail: 

show interfaces Gi1/0/24

Check the switchport configuration: 

show interfaces Gi1/0/24 switchport

Step 4: Is this the endpoint or an uplink?

If the MAC is learned directly from an access port, you have probably found the endpoint.

If the MAC appears on a trunk or uplink, the endpoint is connected to another downstream switch.

Identify the neighboring switch 

show cdp neighbors Gi1/0/24 detail

or: 

show lldp neighbors Gi1/0/24 detail

Then

Connect to the downstream switch and repeat: 

show mac address-table address {{mac}}

Continue until the MAC is learned from the actual access port.

Important concept

The ARP lookup and MAC lookup may happen on different switches. 

Layer 3 switch / gateway

show ip arp 10.10.20.55

        ↓

MAC = 0050.56aa.bbcc

        ↓

Access switch

show mac address-table address 0050.56aa.bbcc

        ↓

Gi1/0/24

ARP tells you which MAC belongs to an IP address. The MAC address table tells you where that MAC address is physically learned.
