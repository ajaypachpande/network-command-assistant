Cisco BGP Troubleshooting

1. Check BGP neighbor state

SAFE 
show ip bgp summary

What to look for

  • Neighbor IP address.
  • Remote AS number.
  • Up/Down timer.
  • State/PfxRcd.

Healthy result

An established IPv4 BGP neighbor normally shows the number of received prefixes in State/PfxRcd.

Problem states 

Idle
Connect
Active
OpenSent
OpenConfirm

2. Neighbor stuck in Active

Active usually means BGP is repeatedly trying to establish its TCP session.

Start with reachability 

ping <neighbor-ip>

Check route to neighbor 

show ip route <neighbor-ip>

Inspect neighbor configuration/state 

show ip bgp neighbors <neighbor-ip>

Check

  • Correct neighbor IP.
  • Correct remote AS.
  • TCP port 179 reachability.
  • Source interface/update-source.
  • eBGP multihop if peer is not directly connected.
  • Authentication mismatch if configured.

3. Neighbor is Established but routes are missing

Check BGP table 

show ip bgp

Check a specific prefix 

show ip bgp <prefix>

Check what you received 

show ip bgp neighbors <neighbor-ip> received-routes

Availability of received-routes output can depend on platform/configuration such as soft reconfiguration.

Check what you advertise 

show ip bgp neighbors <neighbor-ip> advertised-routes

Then inspect

  • Prefix lists.
  • Route maps.
  • AS-path filters.
  • Communities.
  • Network statements.
  • Redistribution.
  • Best-path selection.

4. BGP route exists but is not installed 

show ip bgp <prefix>
show ip route <prefix>

Think about

  • Is this the BGP best path?
  • Does another routing protocol have a better administrative distance?
  • Is the BGP next hop reachable?
  • Is recursion resolving correctly?

Cisco OSPF Troubleshooting

1. Check OSPF neighbors

SAFE 
show ip ospf neighbor

Common states 

DOWN
INIT
2WAY
EXSTART
EXCHANGE
LOADING
FULL

FULL is normally expected when routers need a complete adjacency.

On broadcast networks, seeing 2WAY with some DROTHER neighbors can be normal.

2. Neighbor stuck in INIT

INIT means you are receiving the neighbor's Hello packets, but your own router ID is not being seen in the neighbor's Hello.

Investigate

  • Unidirectional connectivity.
  • ACL/firewall filtering.
  • Layer 2 issues.
  • Multicast delivery.

3. Neighbor stuck in EXSTART / EXCHANGE

Check the interface 

show ip ospf interface

Common checks

  • MTU mismatch.
  • Duplicate router IDs.
  • Packet loss.
  • Interface/network-type mismatch.

4. Check OSPF interface parameters 

show ip ospf interface

Compare between neighbors

  • Area ID.
  • Hello timer.
  • Dead timer.
  • Authentication.
  • Network type.
  • MTU.

5. Check the link-state database 

show ip ospf database

Useful LSA types 

Type 1  Router LSA
Type 2  Network LSA
Type 3  Summary LSA
Type 4  ASBR Summary LSA
Type 5  External LSA
Type 7  NSSA External LSA

Type 3 LSA and high CPU

INVESTIGATE

A Type 3 LSA is generated by an ABR to advertise networks between OSPF areas.

A high number of Type 3 LSAs does not automatically mean the Type 3 LSA itself is the root cause of high CPU.

Look for

  • Repeated LSA churn.
  • Frequent SPF calculations.
  • Flapping interfaces.
  • Flapping OSPF neighbors.
  • Route redistribution instability.
  • Large OSPF databases.
  • Poor summarization between areas.

Check database size 

show ip ospf database

On supported IOS XE platforms, database summary information can help quantify LSAs rather than assuming a particular LSA type is inherently the problem.

Check neighbor stability 

show ip ospf neighbor

Check interfaces 

show ip ospf interface

Check CPU 

show processes cpu sorted

FortiGate BGP / OSPF

BGP summary 

get router info bgp summary

Check neighbor state, AS, uptime, and received prefix count.

BGP neighbor detail 

get router info bgp neighbors

Use when you need more information about a BGP peer than the summary provides.

Routing table 

get router info routing-table all

Confirm that expected BGP or OSPF routes are actually installed.

OSPF neighbors 

get router info ospf neighbor all

Check neighbor state and adjacency.

OSPF interface 

get router info ospf interface

Check which interfaces participate in OSPF and review their operational parameters.

OSPF database 

get router info ospf database brief

Use this when investigating LSAs and database size.

Palo Alto BGP / OSPF

BGP summary 

show routing protocol bgp summary

Use this for a quick BGP peer status overview.

Routing table 

show routing route

Confirm whether expected dynamic routes are installed in the routing table.

Forwarding table 

show routing fib

This helps distinguish a control-plane routing issue from a forwarding-table issue.

OSPF verification

For PAN-OS, verify OSPF adjacency and then verify that OSPF-learned routes appear in the routing and forwarding tables. 

show routing route
show routing fib
