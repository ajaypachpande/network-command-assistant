Terraform Setup

Terraform is an Infrastructure as Code tool. Infrastructure is described using configuration files, and Terraform determines what changes are required.

Installation Goal

Terraform must be installed on the workstation and available through the operating system PATH.

VERIFY TERRAFORM 
terraform version
COMMAND HELP 
terraform -help

Windows Setup Checklist

  • Download and install Terraform.
  • Ensure the Terraform executable is available on PATH.
  • Open a new PowerShell terminal.
  • Run terraform version.
  • Confirm Terraform responds before creating a project.

Typical Terraform Project Structure 

terraform-project/
|
+-- versions.tf
+-- provider.tf
+-- variables.tf
+-- main.tf
+-- outputs.tf
`-- terraform.tfvars

Each file has a different responsibility, but Terraform reads all .tf files in the current working directory as one configuration.
