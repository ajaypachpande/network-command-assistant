Route 53 Hosted Zone and Subdomain Lab

Learn how Terraform can describe a Route 53 public hosted zone and create DNS records for a domain and subdomain.

Learning Goal

Understand the relationship between a domain, a Route 53 hosted zone, and DNS records.

Architecture 

example.com
    |
    v
Route 53 Hosted Zone
    |
    +---- www.example.com
    |
    `---- app.example.com

Important DNS Concept 

Domain Registration
        !=
Route 53 Hosted Zone
        !=
DNS Record

These are separate concepts.

A domain can be registered with one registrar while DNS is hosted in Route 53.

Terraform File Structure 

aws-route53/
|
|-- versions.tf
|-- provider.tf
|-- variables.tf
|-- main.tf
|-- outputs.tf
`-- terraform.tfvars.example

versions.tf

versions.tf 
terraform {
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = ">= 5.0"
    }
  }
}

provider.tf

provider.tf 
provider "aws" {
  region = var.aws_region
}

This portal is educational only. No AWS credentials are required to study this example.

variables.tf

variables.tf 
variable "aws_region" {
  description = "AWS region used by the provider."
  type        = string
  default     = "us-east-1"
}

variable "domain_name" {
  description = "Domain for the hosted zone."
  type        = string
}

variable "www_ipv4" {
  description = "IPv4 address for the www record."
  type        = string
}

variable "app_ipv4" {
  description = "IPv4 address for the app subdomain."
  type        = string
}

main.tf

main.tf 
resource "aws_route53_zone" "primary" {
  name = var.domain_name
}

resource "aws_route53_record" "www" {
  zone_id = aws_route53_zone.primary.zone_id
  name    = "www.${var.domain_name}"
  type    = "A"
  ttl     = 300

  records = [
    var.www_ipv4
  ]
}

resource "aws_route53_record" "app" {
  zone_id = aws_route53_zone.primary.zone_id
  name    = "app.${var.domain_name}"
  type    = "A"
  ttl     = 300

  records = [
    var.app_ipv4
  ]
}

What Terraform Is Describing 

aws_route53_zone.primary
        |
        v
example.com Hosted Zone
        |
        +------ aws_route53_record.www
        |          |
        |          v
        |     www.example.com
        |
        `------ aws_route53_record.app
                   |
                   v
              app.example.com

outputs.tf

outputs.tf 
output "hosted_zone_id" {
  value = aws_route53_zone.primary.zone_id
}

output "name_servers" {
  value = aws_route53_zone.primary.name_servers
}

output "www_record" {
  value = aws_route53_record.www.fqdn
}

output "app_record" {
  value = aws_route53_record.app.fqdn
}
