Terraform Lifecycle

Learn the normal Terraform workflow from project initialization through planning, applying, inspecting state, and cleanup.

Learning Objective

Understand what each Terraform lifecycle command does and why the order matters.

1. terraform init

Initializes the Terraform working directory and prepares provider dependencies.

COMMAND 
terraform init
Read configuration
      |
      v
Find required providers
      |
      v
Initialize provider plugins
      |
      v
Prepare working directory

2. terraform fmt

Formats Terraform configuration into a consistent style.

COMMAND 
terraform fmt -recursive

This is a formatting step. It does not create infrastructure.

3. terraform validate

Checks whether the Terraform configuration is structurally and syntactically valid.

COMMAND 
terraform validate
Terraform files
      |
      v
Syntax / configuration checks
      |
      +--> Valid
      |
      `--> Error found

4. terraform plan

Builds a proposed execution plan showing what Terraform intends to create, change, or remove.

COMMAND 
terraform plan
Configuration
      |
      v
Current state
      |
      v
Terraform compares desired vs current
      |
      v
Execution plan
      |
      +--> create
      +--> update
      `--> destroy
Important

Always review the plan before applying changes.

5. terraform apply

Applies the reviewed Terraform plan and performs the required provider/API operations.

COMMAND 
terraform apply
Reviewed plan
      |
      v
Terraform Core
      |
      v
Provider
      |
      v
Cloud / infrastructure API
      |
      v
Resource changes

This learning portal does not execute terraform apply.

6. Terraform State

Terraform state records the relationship between Terraform resources and the infrastructure being managed.

COMMAND 
terraform state list
Terraform configuration
        |
        v
Terraform state
        |
        v
Known managed resources
Security / Git Rule

Do not commit local Terraform state files to Git.

7. terraform destroy

Removes infrastructure managed by the current Terraform configuration when cleanup is intentionally required.

COMMAND 
terraform destroy

Review the destroy plan carefully before confirming.
